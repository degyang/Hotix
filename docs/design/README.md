## 设计原则

1. **规则引擎主导判断** - 所有判断逻辑由规则引擎完成
2. **LLM 负责解释** - LLM 仅用于语言润色（未实现）
3. **可追溯性** - 每个结论都能追溯到规则 ID
4. **描述性系统** - 描述当前结构，不做预测

## 使用指南

### 何时参考设计文档

- 理解系统的"为什么"（Why）和"是什么"（What）
- 了解架构决策的背景和权衡
- 扩展系统功能时保持设计一致性

### 设计 vs 实施

- 设计文档描述理念和目标
- 实施可能与设计有差异
- 以当前代码为准，设计文档作为参考
